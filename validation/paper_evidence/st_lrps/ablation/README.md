# ablation/

ST-LRPS ablation suite evidence (A0..A6 cumulative progression; optional A7/A8/A9
encodings) written by `--stage ablation`: `st_lrps_ablation_summary.csv` / `.md`
plus per-ablation run dirs. Ablation is **secondary** and does not block
final-candidate evidence. Default is dry-run (commands + manifest); pass
`--execute-ablation` to launch training.
